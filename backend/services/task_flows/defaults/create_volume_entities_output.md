Chỉ trả về một đối tượng JSON tuân thủ JSON Schema đã cho, không kèm code fence hay lời giải thích. Trường gốc phải là characters hoặc factions theo quy định của nhiệm vụ này. Mọi ứng viên đều gồm candidate_ref, ID thực thể chính thức (null nếu tạo mới), profile, state, state_expected_version; không thêm quan hệ, liên kết hay các trường gốc khác.
